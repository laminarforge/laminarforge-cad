# CO2 Incubator CAD Verification

Status: generated and dimension-checked; not biologically validated.

This document records the verification pass for the starter CO2 incubator CAD model.

## Verification Scope

Verified:

- `co2_incubator` builds and regenerates all expected STL outputs.
- STL files are binary STL with valid triangle counts and exact byte lengths.
- Bounding boxes match the intended CAD dimensions.
- The CAD no longer contains an undersized internal CO2 sensor recess based on the rejected MH-Z19B assumption.
- The rear service manifold now includes CO2 inlet, sample outlet, and passive relief holes.

Not verified:

- watertight/manifold topology beyond binary STL structural validity
- print orientation, supports, shrinkage, gasket compression, or tolerance fit
- CO2 leak rate
- temperature stability
- humidity/condensation behavior
- contamination resistance
- real cell-culture suitability

## Design Findings From Verification

### Fixed in this pass

- Removed the internal CO2 sensor recess because it was implicitly sized around a room-air sensor class.
- Added sample outlet and passive relief port to the chamber.
- Added matching manifold holes for CO2 inlet, sample outlet, and passive relief.
- Added `co2_incubator_verify` so future edits fail if expected STL files disappear or dimensions drift unexpectedly.

### Still open

- Select a specific 0-20% CO2 sensor and model the service-bay mount around its actual dimensions.
- Add gas-line hardware details: regulator, solenoid, check valve/filter, relief tubing, and external sample path.
- Add a removable tray handling detail that supports weekly dry/wipe/refill maintenance.
- Add a door/gasket compression model instead of only a static gasket groove.
- Decide whether the final chamber should be printed PETG or built around a known sealable container/liner.
- Add print-orientation and tolerance notes after slicer review.

## Recommendation

Keep this model out of the LaminarForge website until at least the sensor gate, gas gate, thermal gate, and humidity gate are complete.
