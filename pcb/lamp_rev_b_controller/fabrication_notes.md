# Rev B Controller Fabrication Notes

Board: `lamp_rev_b_controller`, Rev B  
Finished outline: 118 x 94 mm  
Layer count/order: `F.Cu / In1.Cu / In2.Cu / B.Cu`  
Plane intent: `In1.Cu` ground; `In2.Cu` power/control  
Finished thickness: 1.6 mm nominal  
Copper: 1 oz outer / 0.5 oz inner  
Base material family: FR-4  
Panelization owner: fabricator; engineering releases one single-up board

These are the only fabrication parameters supported by current repository evidence. The generator must fail until the selected manufacturer/order profile supplies and records the physical dielectric stackup, thickness tolerance, final surface-finish specification and thickness, soldermask/silkscreen colors, finished-hole tolerance, minimum annular ring, acceptance class, and impedance policy. `ENIG preferred` is not a released finish specification.

The fabricator may propose panelization, rails, tooling, fiducials, coupons, and depanelization for the released single-up design, but the proposal is not approved until the portal preview is reviewed. Engineering does not release or authorize a panel Gerber in this package.
